# 🗺️ GEOGRAPHICAL LOGIC

The world must feel geographically believable.

Do not randomly scatter terrain.

Use realistic geographical relationships.

For example:

* Rivers should generally flow downhill.
* Rivers should originate around mountains, highlands, lakes, or other logical sources.
* Major rivers should become larger as tributaries join them.
* Cities should often appear near rivers, coastlines, crossroads, resources, or defensible terrain.
* Roads should follow valleys, passes, coastlines, rivers, and practical terrain.
* Agricultural settlements should generally appear in fertile areas.
* Mining settlements should appear around mountainous/resource-rich regions.
* Desert settlements should cluster around water sources and trade routes.
* Mountain settlements should occupy valleys, passes, plateaus, and defensible locations.
* Forest settlements should have clearings, roads, and nearby resources.
* Major ports should have plausible natural harbors.

The geography should look **designed by nature rather than randomly generated**.

# 🏔️ 3D TERRAIN

The map should have a strong **3D relief / terrain-model appearance**.

Do not simply draw a flat 2D map.

Use actual 3D terrain wherever technically practical.

Mountains should have visible elevation.

Valleys should have depth.

Plateaus should rise above surrounding terrain.

Cliffs should have vertical faces.

Rivers should sit within the terrain.

The camera should allow the user to see the world from an angled perspective.

The default view should feel like looking at a gigantic physical relief map from above.
